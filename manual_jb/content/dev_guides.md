# Development Guides

Pick the row that matches what you're doing. Ordered from easiest to hardest. Each guide builds on the one before it.

| # | Level | Who | Doing what | Guide |
|---|-------|-----|-----------|-------|
| 1 | Beginner | Scientist | Writing a notebook with existing analyses + data | [Notebooks](dev_guides/notebook.md) |
| 2 | Intermediate | Scientist | Writing a new pyincore / pyincore-viz algorithm | [Algorithms](dev_guides/algorithm.md) |
| 3 | Advanced | Developer | Building your own client, or working on UI / Studio / Playbook / pyincore / pyincore-viz | [Clients](dev_guides/clients.md) |
