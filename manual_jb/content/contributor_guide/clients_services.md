# 6. Web clients and services

Web clients (incore-ui, incore-studio, incore-playbook), the Java web services, and building your own client against the IN-CORE APIs are covered in the IN-CORE wiki:

- [IN-CORE Developer Guide](https://github.com/IN-CORE/IN-CORE/wiki/IN%E2%80%90CORE-Developer-Guide): dev access, backends, CORS, building your own client, local services, seed data.
- [IN-CORE Developer Setup](https://github.com/IN-CORE/IN-CORE/wiki/IN%E2%80%90CORE-Developer-Setup): per-repo setup, run and test.

REST API reference: [Swagger](https://tools.in-core.org/doc/api/).
